# Security Policy

CascadeTrace is a simulation and portfolio project, not a production emergency-management system.

If you discover a security issue, avoid publishing exploit details in a public issue. Contact the repository owner through GitHub first so the problem can be reproduced and fixed responsibly.

The deterministic replay fingerprint is an identity/checksum mechanism for a replay. It is **not** a cryptographic signature and should not be treated as authentication or non-repudiation.
