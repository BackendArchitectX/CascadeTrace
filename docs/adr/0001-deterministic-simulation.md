# ADR 0001 — Keep the simulation deterministic

## Status
Accepted

## Context
CascadeTrace models cascading infrastructure failures and lets an operator compare decisions. If model state were generated by an LLM or random process, the same command sequence could produce different outcomes and causal explanations would become difficult to audit.

## Decision
The authoritative simulation remains deterministic. A command ledger plus the scenario seed is sufficient to replay a run. The React client advances the simulation for low-latency interaction. When a scenario ends, the Java service independently replays the ledger and compares its result with the client summary.

The verification API also returns a SHA-256 replay fingerprint derived from the command ledger and deterministic outcome. The fingerprint is evidence of replay identity, not a security signature.

## Consequences
- identical command sequences reproduce identical outcomes;
- counterfactual branches are meaningful and testable;
- causal explanations can point to recorded state transitions;
- Java and TypeScript implementations must remain behaviorally aligned;
- cross-runtime trajectory tests are treated as a compatibility contract.
